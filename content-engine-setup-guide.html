Step 1

Set up your project and connect your tools

  1. Open Claude and add the seo-content, seo-geo and seo-technical skills in Settings → Capabilities (or your plugin marketplace). These are the three writers.
  2. Make a project, name it "SEO Content Engine," and paste the instructions below into Project Settings → Instructions. Add a few lines of your brand voice to project knowledge.
  3. Verify your site in Google Search Console (free, one time). This is what lets Claude see your real queries and which pages are slipping.
  4. Connect the Google Search Console MCP (free, open source, one line, no coding) in Settings → Connectors. Same one used across the SEO set.
  5. Optional, for real keyword volume + intent: add the DataForSEO MCP (official repo, copy the install command from the README) and top up a little at dataforseo.com (pay as you go).
  6. Make sure Scheduled Tasks and Artifacts are on (both native, free). The schedule keeps the Refresher running; the artifact is your live board.

Step 2

The three writers, and the prompt for each

1 · The Columnist

Reads your site, pulls your real queries, clusters them by intent, and drafts pages you do not yet rank for, clearing the E-E-A-T bar.

Prompt
Use seo-technical to crawl [yoursite.com] and pull my real queries from Search Console. Cluster the keyword opportunities by intent (informational, commercial, transactional, navigational), using DataForSEO for volume and difficulty if it is connected. Then with seo-content, draft a page for the best opportunity I do not yet rank for. Make it clear E-E-A-T. Give me the title, meta description, outline, full draft in my voice, target keyword, internal links and schema.

2 · The Refresher fastest wins

Refreshing a slipping post moves you up faster than writing a new one. This finds the decaying pages and the exact issue on each.

Prompt
Pull my Search Console data and find the pages losing position vs the prior 28 days. For each, tell me what is dragging it down: dead FAQ blocks, dated keywords, thin intros, missing schema, keyword cannibalization or a lost featured snippet. Rank them biggest-impact-fastest, propose a fix schedule across this week, and with seo-content give me ready-to-publish rewritten copy plus a changelog, new title and meta, and FAQ schema for the top 3.

3 · The Quotable

Rewrites your passages so AI engines quote you as the source. Then gives you a way to actually test it.

Prompt
Use seo-geo. Take this passage [paste your paragraph] and rewrite it so AI engines will quote it: put the answer in the first sentence under 25 words, keep it self-contained with no vague openers, include one concrete claim or number, keep it 40 to 60 words, question-led. Add a FAQPage schema block. Then give me one test question I can paste into ChatGPT, Claude and Perplexity to check if my page shows up as the source.
Step 2.5 · the live board

Build the live Content Engine

One board that pulls your real Search Console data, auto-flags slipping pages, surfaces keyword gaps by intent, and scores any passage for AI citability.

Prompt
Build me a live artifact called "SEO Content Engine". Before you build, call my Google Search Console MCP once to see the real response shape, then build the parser around what you actually see. On load, pull the last 28 days and the prior 28 days (by query and by page) so you can show deltas. Tabs: the Columnist (keyword opportunities from GSC, clustered by intent), the Refresher (auto-flagged slipping pages + a Copy-all fix prompt) with Search Console data nested inside it, and the Quotable (a live citability scorer + FAQ schema). If the GSC MCP is not connected, show a "Connect Search Console" state instead of faking numbers.

Step 3 · make it run itself

Put the Refresher on autopilot

An artifact only refreshes when you open it. So schedule one tiny task so the engine keeps working when you are not looking.

Prompt
Every Monday at 7am, run the Refresher: pull my latest Search Console data, refresh the board, list any newly slipping pages, and draft the copy fixes for the top 3 so they are ready when I open it.

Now you never open the app to a blank page, the fixes are waiting.
