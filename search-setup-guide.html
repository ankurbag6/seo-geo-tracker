Step 1 · 10 minutes

Get your DataForSEO key

DataForSEO is the data company behind this whole system. They run a database of 270M+ real prompts people type into AI tools (see the live counter on their site) and they can ask ChatGPT, Claude, Gemini and Perplexity questions through one API.

  1. Go to app.dataforseo.com/register and sign up with your email. New accounts come with free trial credit.
  2. Verify your email and log in to the dashboard.
  3. In the left menu, open API Access (app.dataforseo.com/api-access). You will see two things: your API login (your email) and your API password.
  4. Copy both. Important: the API password is a separate generated password, not the one you log in with. It lives only on that API Access page.
  5. That is the whole account setup. Top up later only when the trial credit runs out.
Step 2 · 5 minutes

Run your first live check

  1. Open the tracker. It loads with demo data so you can see what a filled scorecard looks like.
  2. On the Mirror tab, scroll to the ⚙ Live mode box.
  3. Paste your API login and API password, type your brand name and domain, and press Connect. Your real DataForSEO credit balance appears, that is how you know it worked. (Skipped Connect? No problem, Run live connects by itself as long as the two fields are filled.)
  4. Tick the engines you want, then press Run live ▸ on any prompt row. Watch the chips flip to what the engines really said, and a strip appear under the row listing the exact sources each engine quoted, with a verdict on whether you are one of them. The Detective tab's trusted-sources chart also switches to live data built from your runs.

How the live check actually works, in plain English

When you press Run live, the tracker (from your own browser, your key never goes anywhere except DataForSEO) sends your buyer's question to DataForSEO. They actually ask ChatGPT, Claude, Gemini and Perplexity that question, with web search turned on, and pull a real Google AI Overview for it. The full answers come back and the tracker reads them:

  • ✓ cited means your link was in the answer,
  • ◐ mentioned means your name came up with no link,
  • ✗ quiet means you never appeared.

Every score on the board is computed from those answers, nothing is made up. If a call fails you see an error, never a fake result. One honest gap: Copilot has no public API, so the tracker gives you a copy-paste test question and a direct link to check it by hand.

Step 4

The four moves, and the prompt for each

1 · The Mirror

Shows if AI recommends you. Real buyer prompts, checked live across the engines, scored per engine per prompt.

Prompt
You are my AI search visibility analyst. My business: [BRAND], domain [DOMAIN], category [CATEGORY]. 1. Using the seo-dataforseo skill or the DataForSEO MCP, pull the top 15 prompts people ask AI tools in my category, ranked by AI search volume. 2. For each prompt, run it live through ChatGPT, Claude, Gemini and Perplexity with web search on, and check Google AI Overviews via the SERP endpoint. 3. For every answer record: cited (my URL linked), mentioned (named, no link) or quiet, plus every source URL each engine quoted. 4. Output a scorecard: prompt x engine, per-engine visibility %, one overall score. Never invent a result; mark failed calls as failed.

2 · The Detective

Finds why you are invisible: which sources the engines trust, and whether AI can even read your site.

Prompt
Use the seo-geo skill. Take the source URLs my Mirror scorecard collected and audit me against them for [DOMAIN]. 1. Rank the domains the engines quoted most, and mark which ones mention me. 2. Check my site: GPTBot, ClaudeBot, PerplexityBot and Google-Extended access in robots.txt, llms.txt, answer-first blocks, FAQ schema, load speed. 3. Give me the missing signals ranked by impact, each with a one-line reason.

3 · The Fixer

Turns every fail into a paste-ready fix: rewritten copy in the length AI prefers, FAQ schema, crawler permissions, llms.txt.

Prompt
You are my AI-readability fixer for [DOMAIN]. For every fail the Detective found, hand me the exact paste-ready fix: 1. A robots.txt block that lets the AI crawlers in. 2. An llms.txt file describing my site in plain language. 3. An answer-first rewrite of my key pages: answer in the first 25 words, one concrete number, no marketing fluff. 4. FAQPage schema with my real customer questions. Tell me exactly where each snippet goes, and keep my voice.

4 · The Witness the long game

You cannot edit what ChatGPT says, so you earn your way into what it reads: the Reddit threads, directories and best-of lists the engines already quote.

Prompt
You are my citation-earning strategist. From the sources my scorecard collected: 1. List every source I am not on, ranked by citation count x realistic effort (Reddit threads, G2/Capterra style directories, trade press, best-of listicles). 2. For the top 5, draft the exact contribution in my voice: a helpful Reddit reply (value first, never spam), directory blurbs, a 2-line press pitch, an author outreach email. 3. Rules: never astroturf, disclose affiliation where required, and remind me engines re-crawl slowly, recheck in 2 to 4 weeks.

Honest note: this is the slowest move and the strongest one. Fixes show up in days, placements take weeks to get picked up. The tracker's recheck cycle is how you see it land.
